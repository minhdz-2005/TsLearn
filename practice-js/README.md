# Practice JS — cách chạy

Mọi file là ES Module, chạy trực tiếp bằng Node (>= 18), không cần build.

```bash
node practice-js/ex01_variables-types.js      # chạy 1 bài
node practice-js/ex16b_modules.js             # bài module (import ex16a)
```

Cấu trúc mỗi file: comment "ĐỀ BÀI" ở đầu -> code demo có chú giải -> mục
"Bài tập tự làm" ở cuối để bạn tự viết.
